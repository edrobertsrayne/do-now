# Do Now

Spaced-retrieval Do Nows for AQA GCSE Physics, after Craig Barton's Ultimate
Retrieval Tool. Design choices and open risks: [DECISIONS.md](DECISIONS.md).

## Layout

- `bank/*.json` - skills and their recall questions (all `draft` until reviewed; spec refs need checking against the AQA spec).
- `src/lib/scheduler.ts` - pure scheduler: `markTaught`, `unmarkTaught`, `generateDoNow`.
- `src/lib/bank.ts` - bank loader and validation.
- `cli/simulate.ts` - simulate a run of lessons and report scheduling health.
- `src/routes/` - SvelteKit app: home (create/open class), `c/[code]` (taught checklist, Do Now size, generate), `project` (fullscreen Think -> Check view), `print` (one-page sheet), `key` (teacher answer key).
- `src/lib/server/` - class codes, Drizzle schema (`schema.ts`) and `node:sqlite` store (one JSON document per class), bank/store singletons.
- `drizzle/` - SQL migrations generated by drizzle-kit; applied automatically when the store opens.

## Commands

```sh
npm test                                   # scheduler, bank and server-module tests (Node, no build)
npm run typecheck                          # tsc on .ts files
npm run check                              # svelte-check on .svelte and .ts files
npm run simulate -- --lessons 40 --teach-every 2 [--reviewed-only] [--quiet]
npm run db:generate -- --name <change>     # after editing src/lib/server/schema.ts: generate a migration, commit it
npm run dev                                # web app, dev server
npm run bank-editor                        # local question-bank editor at http://127.0.0.1:5175 (dev machine only; PORT/BANK_DIR apply)
npm run build && npm start                 # production server (adapter-node)
```

Env: `DB_PATH` (default `data/retrieval.db`), `BANK_DIR` (default `bank/`), `PORT`, and `ORIGIN` (required behind a proxy for form posts). `drizzle/` is read from the working directory at startup, so deploy it alongside `build/`.

Requires Node with TypeScript type stripping and `node:sqlite` (Node 24+). TypeScript is pinned to 6.x because SvelteKit 3 needs the TypeScript JS API, which TypeScript 7 does not provide.

## Deploying (Railpack on Dokploy)

1. Set the env vars from [`.env.example`](.env.example) in the service's Environment tab. `DB_PATH=/app/data/retrieval.db` and `ORIGIN=https://<your-domain>` are the two that matter.
2. Add a Volume Mount for `/app/data` (Advanced -> Volumes). Without it the database is lost on every redeploy. The directory must be writable by the container user, since SQLite also writes `-wal` and `-shm` files beside the database.
3. The store creates the database directory if it is missing and applies `drizzle/` migrations on startup, so no manual DB setup is needed.
